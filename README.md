# ACE.Corp — Boceto web 3.0

Web estática responsive para GitHub Pages.

## Novedades 3.0
- Animaciones de aparición al desplazarse por la página.
- Entradas laterales y escalonadas para tarjetas y textos.
- Barra superior de progreso de lectura.
- Respeto por la preferencia del sistema de reducir movimiento.
- Rutas de imágenes relativas explícitas y aviso visual alternativo si falta un archivo.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño responsive negro/naranja/rojo.
- `script.js`: navegación móvil y cesta demostrativa.
- `assets/`: logotipo oficial ACE.Corp (PNG) y logotipo RePapèr (PNG).

## Probar en local
Abre `index.html` con un navegador.

## Publicar con GitHub Pages
1. Crea un repositorio en GitHub, por ejemplo `ace-company-web`.
2. Sube todos los archivos y carpetas de este proyecto (no solo el HTML).
3. En el repositorio, entra en **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona `main` y `/ (root)` y guarda.
6. Espera a que GitHub Pages publique la web y te muestre la dirección.

## Notas
- No necesita Python ni backend: GitHub Pages publica HTML, CSS y JavaScript estáticos.
- La cesta es una demostración. No procesa pedidos ni pagos.
- El precio de 16 € es provisional.
- El enlace de RePapèr apunta a la dirección facilitada.
- Las fuentes de Google Fonts requieren conexión a Internet; si no están disponibles, se usan fuentes alternativas.


## Importante al subirlo a GitHub
Sube también la carpeta `assets` completa. La web necesita estos dos archivos, con estos nombres exactos (en minúsculas):
- `assets/ace-logo.png`
- `assets/repaper-logo.png`

Los nombres distinguen mayúsculas y minúsculas; no los renombres.
